# Somnia Agentathon Mini-Grant Requirements

Applicants should submit public evidence that their project is real, inspectable, and runnable.

Required evidence:

- Public GitHub repository.
- README or setup documentation.
- Deployed contract address on Somnia testnet, where applicable.
- Demo transaction, hosted demo, or short demo video.
- Tests, smoke proof, or transaction proof showing the flow works.

Optional evidence:

- Project website or demo page.
- Architecture notes.
- Known limitations and next steps.

Agent screening should return one bounded verdict:

- `Complete`: all required evidence appears present.
- `NeedsReview`: most evidence is present, but at least one important item is unclear.
- `Incomplete`: required evidence is missing or clearly not working.

Judges select finalists manually after reviewing the screened evidence. Agent verdicts do not select winners or move funds.
